O que é Node.js

Execute JavaScript em Qualquer Lugar

O Node.js® é um ambiente de execução JavaScript gratuito, de código aberto e multiplataforma, que permite aos desenvolvedores criar servidores, aplicativos web, ferramentas de linha de comando e scripts.

O que é o NPM e o package.json

O NPM (Node Package Manager) é o gerenciador de pacotes padrão para o Node.js. Ele funciona como um enorme repositório e uma ferramenta de linha de comando que permite baixar, instalar, atualizar e compartilhar bibliotecas e códigos reutilizáveis criados por outros desenvolvedores.

O package.json é o arquivo de configuração principal (ou a "identidade") de um projeto JavaScript/Node.js. Ele armazena metadados sobre o projeto e atua como uma lista de instruções do que o sistema precisa para funcionar.
