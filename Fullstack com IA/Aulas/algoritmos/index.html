Repetição

  • Os principais comandos de repetição em JavaScript são: for, while e do...while. Eles servem para executar um bloco de código várias vezes de forma automática.

- Contagem de 1 até 10

Funções

  • Funções em JavaScript são blocos de código reutilizáveis criados para executar tarefas específicas, representados principalmente por Função Declarada, Função Expressa e Arrow Function (função de seta). Elas ajudam a organizar o programa e evitam repetir códigos

- Nome completo

Arrays

  • Em JavaScript, um array é um objeto global utilizado para armazenar múltiplos valores em uma única variável. Eles possuem tamanho dinâmico, são indexados a partir do zero e podem conter elementos de tipos variados simultaneamente (strings, números, objetos, etc.).

- Listas de frutas.

Array de objetos

  • Um array de objetos em JavaScript é uma lista estruturada onde cada item é um objeto com propriedades e valores. É essencial para armazenar e manipular conjuntos de dados complexos.

- Nome e idade de clientes.
