Planejamento
Página com fundo branco e fonte Roboto como principal.
O objetivo é ter uma landing page clean, branca e sofisticada.

SEÇÃO HEADER:
Logo no canto esquerdo 
A logo é um F em um círculo (feito com CSS)
O fundo do círculo é verde escuro

Botão de download no canto direito 
fundo verde, cor branca
borda arredondada

SEÇÃO HERO SECTION:
A hero deve ter a altura 90vh, dividido em 3 áreas horizontais

Esquerda:
Apenas a headline, sem ser grande demais, sem destaque (o destaque é o print do app no meio).
“O app perfeito para acompanhar a sua vida fitness.”

Centro:
Em destaque a imagem estilo/imagem/print_1.png que é um print do app.

Direita:
Uma lista de pontos-chave sobre o app:
Saúde
Exercício
Amigos 

SEÇÃO DE FUNCIONALIDADES:
Vão ser usadas  as imagens estilo/imagem/print_2.png, estilo/imagem/print_3.png e estilo/imagem/print_4.png que serão exibidas da seguinte forma:
print / texto
texto / print
print / texto
Ou seja, irá alternar entre o print na esquerda e um texto explicativo na direita e vice-versa.

Descrição breve de cada print para você gerar um texto adequado:
print_2.png = Contagem de calorias 
print_3.png = Exercícios específicos (Corrida, musculação, flexão, prancha, etc…)
print_4.png = Compartilhamento com amigos

SEÇÃO DE CTA (CLL_TO_ACTION):
Botão grande de download com um texto abaixo dele destacando:
“Totalmente gratuito”

SEÇÃO DE RODAPÉ:
Apenas com o texto “todos os direitos reservados”
